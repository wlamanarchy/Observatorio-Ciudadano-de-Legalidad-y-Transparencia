# Modelo de riesgos democráticos y controles

| Riesgo | Control mínimo |
|---|---|
| Cuentas múltiples / bots | niveles de verificación, rate limiting, detección de anomalías, una elegibilidad por persona/proceso |
| Brigading o movilización coordinada | publicar distribución temporal y territorial; no invalidar coordinación política legítima; investigar solo señales técnicas de abuso |
| Captura institucional | roles separados, auditoría, reglas congeladas, conflictos de interés y trazabilidad de cambios |
| Sesgo de moderación | reglas neutrales, motivación, recurso, muestreo de calidad y estadísticas públicas |
| Manipulación algorítmica | registro de algoritmos, código/reglas auditables y resultados oficiales independientes del feed personalizado |
| Desinformación | exigencia de fuentes para afirmaciones verificables, derecho de contradicción y distintivos de evidencia; no censura por mera controversia |
| Exclusión digital | canales asistidos y presenciales, accesibilidad, lenguaje claro, bajo consumo de datos y carga offline con control de duplicados |
| Sobrerrepresentación de grupos organizados | reportar participación y distribución; no proclamar representatividad estadística sin diseño muestral |
| Compra/coacción de voto | voto secreto o pseudónimo según nivel, prohibición de comprobante que revele selección, monitoreo de patrones y canal de denuncias |
| Cambio de reglas a mitad de proceso | hash/versionado de reglas y congelamiento previo a votación |
| Acceso indebido a identidad | separación de tablas, RLS, MFA administrativa, logs de acceso y minimización |
| Reidentificación de minorías | umbrales mínimos para publicar desagregaciones y supresión de celdas pequeñas |
| Uso partidista de recursos públicos | trazabilidad institucional, declaración de convocante, neutralidad de la interfaz y archivo público de comunicaciones |
| Confundir consulta con obligación jurídica | etiqueta visible de naturaleza jurídica en todo proceso y resultado |

## Incidentes

Todo incidente que pueda afectar integridad de la participación debe tener: identificador, severidad, periodo afectado, datos comprometidos, decisión adoptada, responsable de revisión, impacto sobre resultados y resolución pública cuando sea posible.

Una votación comprometida no se “corrige” silenciosamente: se audita y, si la integridad no puede demostrarse, se anula y repite bajo reglas publicadas.
